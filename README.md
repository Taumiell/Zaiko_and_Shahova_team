# спешл фо

Афиша локальных событий Нижнего Новгорода. Сайт собирает события, тематические подборки и статьи в одном месте.

(написание кода было делигировано чату гпт)

## Запуск

Установить зависимости:

```bash
yarn install
```

Запустить сервер разработки:

```bash
yarn start
```

Собрать production-версию в `docs/`:

```bash
yarn build
```

## Страницы

- `index.html` — главная;
- `about.html` — о проекте;
- `placeholder.html` — временная заглушка для разделов, которые пока не реализованы.

Страницы собираются Webpack из шаблонов в `src/`. Статические изображения и SVG находятся в `public/assets/`; production-сборка копирует эту папку в `docs/public/`.
